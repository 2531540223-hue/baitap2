# WEBSITE GIỚI THIỆU ĐÀ NẴNG

## 1. Giới thiệu

Đây là website tĩnh giới thiệu về thành phố Đà Nẵng.

Website được xây dựng nhằm giới thiệu các địa điểm du lịch,
ẩm thực, hoạt động vui chơi, văn hóa, kinh nghiệm du lịch
và các loại hình lưu trú tại Đà Nẵng.

Website được phát triển bằng HTML5 và CSS3.

---

## 2. Các trang của website

Website gồm 08 trang HTML:

## 5. Responsive

Website hỗ trợ:

- Desktop
- Tablet
- Mobile

CSS sử dụng Media Query để thay đổi bố cục
theo kích thước màn hình.

### Desktop

Grid có thể hiển thị 4 cột.

### Tablet

Grid chuyển xuống 2 cột.

### Mobile

Grid chuyển xuống 1 cột.

Navigation trên điện thoại chuyển thành
dạng danh sách dọc.

Hình ảnh sử dụng:

- max-width: 100%;
- object-fit: cover;

nhằm hạn chế tình trạng hình ảnh bị tràn
hoặc biến dạng.

Website cũng sử dụng:

overflow-x: hidden;

để tránh xuất hiện thanh cuộn ngang không cần thiết.
